# WOTW-NX

Unofficial Nintendo Switch homebrew port of **Tom and Jerry: War of the Whiskers**, featuring local multiplayer and Switch controls. This is an experimental build that requires user-supplied game files.

I wanted to play this game on my Switch, either solo or against friends in local multiplayer, so I started working on bringing it over. After plenty of testing and adjustments, it now runs and is playable!

## Credits

This project uses [shihabal3amri’s Tom and Jerry: War of the Whiskers PC port](https://github.com/shihabal3amri/tom-jerry-war-of-the-whiskers-pc/releases) as the foundation for the Switch version. Credit for the original PC port goes to its author and contributors.

## Performance

The game is playable, but there are still limitations:

* Loading assets can cause temporary slowdown.
* Matches with four characters can experience sustained slowdown.
* The game does not consistently run at 60 FPS.

## Development status

For now, I’ve reached a dead end with further performance improvements. I may not continue development, so additional updates are not guaranteed.

I’ll provide the source code and the files needed to run the Switch port so others can try it, inspect the work, and potentially continue improving it. I’ll also provide both PlayStation-style and Switch-style control mappings for anyone who needs them. Players will still need to supply their own compatible game files.

I hope sharing the project helps someone pick up where I left off.
