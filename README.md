# 🐱 WOTW-NX

**Unofficial Nintendo Switch homebrew port of Tom and Jerry: War of the Whiskers (Original Xbox)**, featuring **stable 60 FPS gameplay, four-player local multiplayer, expanded tournament modes, and achievements!**

I originally started this project because I wanted to enjoy Tom and Jerry: War of the Whiskers on my Nintendo Switch, both solo and with friends.

After extensive development, testing, and optimization, WOTW-NX has become a complete and fully playable Nintendo Switch port, with several additions that expand on the original game.

**📦 [Download the Latest Release](https://github.com/JohnJames29/WOTW-NX/releases/latest)**

## 🎮 Features

- Original Xbox gameplay on Nintendo Switch.
- Local multiplayer for up to four players.
- Support for single Joy-Con, Pro Controller, and handheld controls.
- Switch-style and PlayStation-style button layouts.
- Original game characters, arenas, music, and sound effects.
- Saving and loading game progress with up to four save profiles.
- Expanded tournament modes, achievements, and difficulty levels.
- Optimized ARM64 JIT and deko3d rendering.

## 🚀 Performance

WOTW-NX delivers smooth gameplay thanks to its optimized ARM64 JIT and deko3d renderer.

- **Stable 60 FPS** at 720p handheld and 1080p docked.
- **No overclocking required!**
- Smooth gameplay even during demanding four-player matches.
- Optimized graphics rendering and CPU performance.
- SaltyNX FPS monitoring support.

**Performance has been tested on a Nintendo Switch OLED, maintaining approximately 60 FPS (59.9–60.3 FPS) without noticeable drops.**

## 🏆 Tournament Modes

Alongside the original Classic Tournament mode, WOTW-NX includes two additional modes:

- **Elimination Tournament:** Compete in knockout brackets with up to 32 participants.
- **League Tournament:** Compete in a league format with standings and match progression.

Tournament features include:

- Melee, Team, and Tag configurations.
- Up to 32 tournament participants.
- Custom participant names.
- **32 player colors to choose from.**
- Hot-seat multiplayer for larger tournaments.
- Tournament progression and results tracking.

## 🎖️ Achievements

WOTW-NX includes **55 achievements**, based on the [RetroAchievements set](https://retroachievements.org/game/21156).

- All 55 achievements supported.
- In-game achievement unlock notifications.
- Dedicated Achievements menu under Options.
- Achievement progress saved separately for each profile.
- Recognition of eligible accomplishments from existing saves.

## 🤖 Difficulty Levels

Five difficulty levels are available:

- Easy
- Medium
- Hard
- **Extreme**
- **Unfair**

Extreme and Unfair feature smarter CPU opponents with improved attacking, defending, counterattacking, movement, and combat decisions.

## 📥 Installation

**You must provide your own compatible original Xbox game files. Game assets are not included in this release.**

### Option 1: Windows Installer (Recommended)

1. Visit the **[Latest Release](https://github.com/JohnJames29/WOTW-NX/releases/latest)** page.
2. Download `Setup-WOTW.exe`.
3. Run the installer and follow the instructions to prepare your original game files.
4. Copy the prepared game folder from `Switch-ready` to your Nintendo Switch microSD card.
5. Launch WOTW-NX through the Homebrew Menu.

### Option 2: Manual Installation

1. Visit the **[Latest Release](https://github.com/JohnJames29/WOTW-NX/releases/latest)** page.
2. Download your preferred package:
   - **Switch Controls:** For Nintendo Switch-style button layouts.
   - **PlayStation Layout:** For PlayStation-style button layouts.
3. Extract the ZIP file.
4. Follow the included installation instructions and add your compatible original Xbox game files.
5. Copy the prepared game folder to your Nintendo Switch microSD card.
6. Launch WOTW-NX through the Homebrew Menu.

## 🔄 Updating

### Option 1: Windows Installer (Recommended)

1. Download the latest `Setup-WOTW.exe` from the **[Releases Page](https://github.com/JohnJames29/WOTW-NX/releases/latest)**.
2. Run the installer and follow the instructions.
3. Copy the updated files from `Switch-ready` to your Nintendo Switch microSD card.
4. Launch the updated game through the Homebrew Menu.

### Option 2: Manual Update

1. Visit the **[Latest Release](https://github.com/JohnJames29/WOTW-NX/releases/latest)** page.
2. Download the updated Switch Controls or PlayStation Layout package.
3. Extract the ZIP file and follow the included update instructions.
4. Copy the updated files to your existing installation while preserving your original game files and save profiles.

**Important:** Back up your existing saves and profiles before updating. Do not delete your existing game directory.
